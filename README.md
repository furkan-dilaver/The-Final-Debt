# The Final Debt

A cinematic crime-thriller story game being developed in Unreal Engine.

## About the Game

The Final Debt follows Elias Vane, a former criminal trying to leave his past behind.

When an old contact offers him one final job, a simple car theft quickly turns into a conspiracy involving corruption, betrayal, hidden records, and a woman named Mara.

The player must survive dangerous missions, uncover the truth about Elias' past, and make choices that affect the ending.

## Planned Features

- Cinematic story-driven gameplay
- Driving sequences
- Stealth
- Third-person combat
- Dialogue choices
- Multiple endings
- Crime-thriller atmosphere
- Unreal Engine cinematics
